# PDFs dos resultados

Esta pasta reúne os PDFs gerados para leitura e entrega. Ela substitui
output/pdf/. Os geradores ficam em codigo_fonte/analises_e_relatorios/.

Os arquivos PDF são locais e podem ser recriados pelos comandos do
[catálogo](../../codigo_fonte/COMANDOS.md). Preserve os relatórios e manifestos
da execução correspondente em [resultados/relatorios/](../relatorios/).
