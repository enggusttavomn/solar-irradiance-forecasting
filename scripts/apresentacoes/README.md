# Apresentações

Pontos de entrada para gerar, corrigir e inspecionar slides. Execute-os como
módulos a partir da raiz: `python -m scripts.apresentacoes.<comando>`.

Consulte os comandos e os insumos necessários no
[catálogo](../COMANDOS.md#utilitários-com-interface-histórica).
As implementações e seus caminhos históricos são preservados.
